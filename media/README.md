Drop your photos, video clips and the song recording here.

- Song: `song.mp3` (or .wav / .m4a, set the name in project.json)
- Shots: name each file after its shot id from SHOT_LIST.md, e.g.
  `s14-cheyenne-porch.jpg` or `s14-cheyenne-porch.mov`.
  Any common photo or video type works. Phone portrait shots are fine.

This folder is git-ignored so your family photos never get pushed.
